## Text Reversal Guide

This application provides text reversal
functionality.

### Available Operations

- Reverse character order
- Reverse word order
- Display processed text
- Copy generated results (if supported)

### How to Use

1. Enter the original text.
2. Select a reversal operation.
3. Review the generated result.
4. Copy the result if needed.

### Development Notes

Handle spaces and punctuation
consistently during text processing.
